# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities through this repository's private vulnerability reporting on the **Security** tab (Security → Report a vulnerability). That is the channel both existing advisories arrived on.

If private reporting is unavailable, email [hello@ref.tools](mailto:hello@ref.tools).

You can expect a first response within a few days.
